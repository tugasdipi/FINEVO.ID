# FinEvo.id — GitHub Pages Ready

File utama: `index.html`

## Deploy cepat
1. Buat repository GitHub baru.
2. Upload `index.html` dan `.nojekyll` ke root repository.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch **main** dan folder **/(root)**, lalu **Save**.
6. GitHub Pages akan menerbitkan situs di alamat `https://USERNAME.github.io/NAMA-REPOSITORY/`.

Catatan: build ini menyimpan progres siswa di `localStorage` browser. Data tersebut tersimpan per browser/perangkat dan bukan database online.
